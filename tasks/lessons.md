# Enseignements

- Comparer les technologies selon les priorités exprimées avant de recommander
  une stack. Ici : distribution macOS/Linux et orchestration d'outils natifs.
  Distinguer performance du CLI et performance de l'inférence ; l'existence
  d'un SDK officiel ne suffit pas à décider du langage.
- Lorsque l'utilisateur affine une liste, conserver sa sélection exacte :
  les exports V1 sont TXT, Markdown et JSON. SRT a été proposé puis écarté.
- Distinguer le binaire applicatif de l'installation complète. Go simplifie
  la distribution du CLI ; les outils audio, YouTube et modèles restent à gérer.
- Privilégier la langue produit demandée explicitement : ici CLI et README en
  anglais, même si les échanges de travail sont en français. Pour le README,
  garder un ton simple et une procédure d'installation globale concrète.
